# 每日籌碼檢查工作流 (完整版)

### 執行指南
當啟動此 Workflow 時，必須讀取用戶上傳的參考檔案（如：20因子-test.md），並「逐一執行」F01 至 F05 的所有任務。

---

### 任務步驟
1. **完整讀取清單**：提取檔案中 F01、F02、F03、F04、F05 的所有定義與網址。
2. **逐項抓取數據**：
   * **F01-F03**：抓取外資「未平倉」的多、空、淨額。
   * **F04**：抓取台指期貨「當日收盤價」。
   * **F05**：抓取「選擇權總成交量」。
3. **數據檢核**：確認五項指標數值皆已取得，若當日無資料則查前一交易日。

---

### 報告輸出格式 (必須包含以下項目)
在 Open Editor 更新「每日籌碼報告.md」，格式如下：

## 每日籌碼報告 ([日期])
| 指標編號 | 項目名稱 | 數據 |
| :--- | :--- | :--- |
| F01 | 外資期貨淨額 | [數值] |
| F02 | 外資期貨多方 | [數值] |
| F03 | 外資期貨空方 | [數值] |
| F04 | 台指期當日收盤價 | [數值] |
| F05 | 選擇權總成交量 | [數值] |
