# 📨 訊息範本

此範本用於角色間通訊，請複製並填入實際內容後貼到接收者的收件匣。

---

## 標準訊息格式

```markdown
### [ ] YYYY-MM-DD HH:MM - 來自 [角色標記] [角色名稱]

> **訊息 ID**: msg_YYYYMMDD_HHMMSS
> **優先級**: 🔴 高 / 🟡 中 / 🟢 低
> **類型**: 📋 任務請求 / 💬 資訊通知 / ❓ 問題詢問 / ✅ 完成回報

**主旨**: [簡短描述訊息主題]

**內容**:
[詳細說明訊息內容]

**相關檔案**:
- `path/to/file1.py`
- `path/to/file2.md`

**請接收者執行**:
- [ ] [待辦事項 1]
- [ ] [待辦事項 2]
- [ ] [待辦事項 3]

**回覆方式**:
請回覆至 `.communication/[發送者角色]_inbox.md`

---
```

## 訊息範例

### 範例 1: 任務請求

```markdown

> **優先級**: 🟡 中

**內容**:
已完成 F01 自動化測試腳本的通過率計算邏輯優化，修正了「預期錯誤被誤計為失敗項目」的問題。
測試通過率應該從 55.6% 正確顯示為 100%。

**相關檔案**:
- `dev/f01_package/test_f01_auto.py` (v2.0)

**請測試專員執行**:
- [ ] 執行測試腳本 `python dev/f01_package/test_f01_auto.py`

```

## 快速參考

### 角色標記
- 💻 開發專員 (Development Specialist)
- 🧪 測試專員 (Testing Specialist)
- 📚 文件專員 (Documentation Specialist)
- 🏗️ 架構專員 (Architecture Specialist)

### 收件匣路徑
- `.communication/dev_inbox.md` - 開發專員
- `.communication/test_inbox.md` - 測試專員
- `.communication/doc_inbox.md` - 文件專員
- `.communication/arch_inbox.md` - 架構專員

### 優先級
- 🔴 高：需要立即處理
- 🟡 中：正常優先級
- 🟢 低：可延後處理

### 訊息類型
- 📋 任務請求：需要接收者執行特定任務
- 💬 資訊通知：僅通知，無需回覆
- ❓ 問題詢問：需要接收者回答問題
- ✅ 完成回報：回報任務完成狀態
