## 🎯 功能規格

### 核心功能

**輸入**:
- 日期字串（YYYY-MM-DD 格式），例如："2025-12-17"

**輸出**:
- **成功格式**: `"2025.12.17  F12: 台股每日成交金額 : 4,567.89 [TWSE]"`
- **失敗格式**: `"F12 錯誤: [錯誤訊息] [TWSE]"`

**數據來源**:
- TWSE 官網: https://www.twse.com.tw/zh/trading/historical/fmtqik.html
- 查詢參數: `?date=YYYYMMDD&response=html`

## 🏗️ 技術實現

### 架構設計

```python
模組結構:
├── 配置區塊
│   ├── URL 常數
│   ├── Timeout 設定
│   └── 欄位名稱變異清單
├── 日誌配置
│   └── [F12] 前綴 logger
├── 主函式 fetch(date: str) -> str
│   ├── 1. 日期驗證與格式轉換
│   ├── 2. HTTP GET 請求
│   ├── 3. HTML 表格解析 (pandas.read_html)

│   └── 5. 格式化輸出
└── 輔助函式
    ├── _validate_and_format_date()
    ├── _extract_turnover()
    ├── format_success()
    └── format_error()
```

### 關鍵決策

| 決策 | 選擇 | 理由 |
|------|------|------|
| **HTTP 請求** | `requests` | 標準、穩定、易於測試 |
| **HTML 解析** | `pandas.read_html()` | 自動解析表格，減少手動邏輯 |
| **日期格式** | YYYYMMDD (查詢參數) | TWSE API 要求 |
| **異常處理** | 捕捉所有異常轉文字 | 符合專案規範，不拋出異常 |
| **欄位識別** | 多個欄位名稱變異 | 處理 TWSE 網頁不規則空白 |

## 🔧 異常處理清單

模組完整處理以下 6 種異常：

1. **requests.Timeout**
   - 訊息: `"F12 錯誤: 連線逾時 [TWSE]"`
   - 觸發: HTTP 請求超過 10 秒

2. **requests.HTTPError**
   - 訊息: `"F12 錯誤: HTTP {status_code} [TWSE]"`
   - 觸發: HTTP 4xx/5xx 錯誤

3. **requests.ConnectionError**
   - 訊息: `"F12 錯誤: 網路連線失敗 [TWSE]"`
   - 觸發: 無網路或 DNS 失敗

4. **ValueError**
   - 訊息: `"F12 錯誤: 日期格式無效 [TWSE]"` 或 `"資料解析失敗"`
   - 觸發: 無效日期或數值轉換失敗

5. **KeyError**
   - 訊息: `"F12 錯誤: 欄位缺失 [TWSE]"`
   - 觸發: 表格缺少必要欄位

6. **IndexError**
   - 訊息: `"F12 錯誤: 資料格式異常 [TWSE]"`
   - 觸發: 表格索引超出範圍
