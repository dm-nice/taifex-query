# F07: 臺指選擇權(TXO)買賣權未平倉量比率%

## 1. 模組概觀
- **模組名稱**: `f07_fetcher`
- **功能**: 抓取每日 TXO (臺指選擇權) 買賣權未平倉量比率 (Put/Call Open Interest Ratio)。
- **目標欄位**: `買賣權未平倉量比率%` (Put/Call Open Interest Ratio %)
- **輸出代號**: `F07`

## 2. 資料來源
- **URL**: `https://www.taifex.com.tw/cht/3/pcRatio`
- **HTTP Method**: GET
- **參數**: `queryDate=YYYY/MM/DD` (雖然 API 接受此參數，但實際 **無視日期**，固定回傳最新交易日數據)
- **資料特性**:
  - ⚠️ **API 限制**: 無法查詢歷史數據，只能抓取最新一天。
  - 回傳 HTML 表格。
  - 數值單位為百分比 (%)，網頁直接顯示如 `142.73`，無需再乘以 100。

## 3. 輸出格式 (v5.0)
遵循專案標準格式：
`[YYYY.MM.DD]  [模組代號]: [中文名稱] : [數值]% [Tail]`

### 成功範例 (Success)
```text
2025.12.10  F07: 臺指選擇權(TXO)買賣權未平倉量比率% : 142.73% [TAIFEX]
```
*(注意：數值後方需加上 `%` 符號)*

### 失敗範例 (Error)
```text
2025.12.10  F07 錯誤: 找不到表格欄位 [TAIFEX]
```

## 4. 實作細節
### 欄位對應
- 網頁表格欄位名稱可能為 `買賣權未平倉量比率%` 或 `買賣權未平倉量比率\%`。
- 建議使用模糊搜尋 `["未平倉量比率", "Open Interest Ratio"]` 進行定位。

### 數值處理
- 來源數值通常為 float (e.g., `142.73`)。
- 輸出時保留原值，並在字串末尾附加 `%`。

### 錯誤處理
1. **無資料 (休市/未產出)**: 
   - 若表格為空或找不到日期，回報「該日無交易資料」。
2. **日期格式錯誤**:
   - 若輸入日期無法解析，回報「日期格式錯誤」。
3. **連線失敗**:
   - Retry 3 次，若仍失敗則回報 HTTP Error。
