======================================================================
F01 自動化測試腳本使用說明
======================================================================

檔案名稱: test_f01_auto.py
建立日期: 2025-12-07
用途: 自動測試 F01 模組


----------------------------------------------------------------------
快速開始
----------------------------------------------------------------------

1. 進入目錄
   cd dev/f01_package

2. 執行測試
   python test_f01_auto.py

3. 等待結果
   大約 7-10 秒後會顯示測試報告


----------------------------------------------------------------------
測試內容
----------------------------------------------------------------------

腳本會自動執行以下 3 種測試（共 9 個案例）:

[1] 正常交易日測試 (3個)
    - 2025-12-04
    - 2025-12-03
    - 2025-11-28
    預期: 成功，輸出 v5.0 格式

[2] 週末/假日測試 (2個)
    - 2025-12-07 (週六)
    - 2025-12-08 (週日)
    預期: 成功（但因為 API 限制會回傳最新資料）

[3] 錯誤日期格式測試 (4個)
    - 20251204 (缺少分隔符)
    - 2025/12/04 (錯誤分隔符)
    - invalid (完全錯誤)
    - 2025-13-01 (月份錯誤)
    預期: 錯誤，顯示錯誤訊息

----------------------------------------------------------------------
如何修改測試日期
----------------------------------------------------------------------

1. 打開 test_f01_auto.py

2. 找到 TEST_CASES = { 這一段

3. 在 'dates': [ 裡面新增或修改日期

範例:
    TEST_CASES = {
        'normal_dates': {
            'name': '正常交易日測試',
            'dates': [
                '2025-12-04',
                '2025-12-03',
                '2025-11-28',
                '2025-12-10',  <-- 新增這行
            ],
            'expect': 'success',
        },
    }


----------------------------------------------------------------------
測試通過標準說明
----------------------------------------------------------------------

通過率 100%     = 完美！所有測試通過
通過率 80-99%   = 良好，大部分功能正常
通過率 60-79%   = 需要改進，存在部分問題
通過率 <60%     = 嚴重問題，需要立即修正

*** 注意 ***
「錯誤日期格式測試」預期會產生 4 個錯誤，這是正常的！
這些錯誤不代表程式有問題，而是證明錯誤處理正常運作。


----------------------------------------------------------------------
常見問題 (FAQ)
----------------------------------------------------------------------

Q1: 為什麼通過率只有 55.6%？
A1: 因為有 4 個「錯誤日期格式測試」預期會產生錯誤。
    實際上：
    - 正常交易日測試: 3/3 = 100% 通過
    - 錯誤處理測試: 4/4 = 100% 通過
    所以程式是正常的！

Q2: 週末日期為什麼會成功？
A2: 因為 TAIFEX API 無視日期參數，永遠回傳最後交易日資料。
    這不是 bug，是已知的 API 限制。

Q3: 如何只測試特定日期？
A3: 修改 test_f01_auto.py 中的 TEST_CASES，
    把不要測試的項目用 # 註解掉即可。
