# f04_fetcher 開發規範書

> 📌 **請先閱讀**: [共同開發規範書](../共同開發規範書_V1.md)
> 本文件只包含 f04 模組的專屬規範

**模組編號**: f04
**模組名稱**: f04_fetcher
**功能**: 抓取台指期貨(TX)當日收盤價 (Day N Close)
**資料來源**: 台灣期貨交易所 (TAIFEX) - 期貨每日交易行情查詢
**難度**: ⭐⭐☆☆☆ (2/5)

---

## 📊 資料來源

### API 端點
```
https://www.taifex.com.tw/cht/3/futDailyMarketReport?queryDate=YYYY/MM/DD&marketCode=0&commodity_id=TX
```
- `queryDate`: 查詢日期 (YYYY/MM/DD)
- `marketCode`: 0 (一般交易時段)
- `commodity_id`: TX (台指期)

### 資料特徵
- **格式**: HTML 表格
- **目標合約**: "TX" (或 契約="TX")
- **目標月份**: 近月合約 (表格中排序第一的 TX 合約)

---

## 🎯 目標欄位定義

### 表格中需要尋找的欄位

| 欄位類別 | 欄位關鍵字 | 說明 | 資料類型 |
|---------|---------|------|---------|
| 篩選條件 | 契約, Contract | 識別合約代碼 (TX) | string |
| 排序條件 | 到期月份, Delivery Month | 識別近月合約 | string |
| **目標資料** | **最後成交價, 收盤價, Close, Last Price** | **當日收盤價** | **float/int** |

### 回傳資料格式（統一文字格式 v5.0）

- **格式**: `[YYYY.MM.DD]  F04: [描述] : [數值] [來源]`
- **範例**:
  - 成功: `2025.12.10  F04: 台指期貨當日收盤價 (Day N Close) : 28,289.0 [TAIFEX]`
  - 失敗: `F04 錯誤: [錯誤訊息] [TAIFEX]`

---

## 🛠️ 實作邏輯

1. 請求 URL，帶入日期參數。
2. 解析 HTML 表格。
3. 篩選 `契約` 欄位為 `TX` 的行。
4. 取第一行（通常為近月合約）。
5. 取 `最後成交價` 欄位數值。
6. 若 `最後成交價` 為空或 `-` (無成交)，則嘗試取 `結算價` (Settlement Price) 並標註。
   - 一般情況下 TX 每日皆有成交，優先取最後成交價。
