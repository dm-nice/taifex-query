# f02_fetcher 開發規範書

> 📌 **請先閱讀**: [共同開發規範書](../共同開發規範書_V1.md)
> 本文件只包含 f02 模組的專屬規範

**模組編號**: f02
**模組名稱**: f02_fetcher
**功能**: 抓取台指期貨外資的**未平倉多方口數** (Open Interest - Long)
**資料來源**: 台灣期貨交易所 (TAIFEX)
**難度**: ⭐⭐☆☆☆ (2/5)

**⚠️ 重要限制**: 本模組使用的 API 端點無視日期參數，永遠回傳最後交易日資料（同 F01）

---

## 📊 資料來源

### API 端點
```
https://www.taifex.com.tw/cht/3/futContractsDate?queryType=1&marketCode=0&date=YYYY/MM/DD
```
*註：與 F01 模組共用相同的資料源網址*

### 資料特徵
- **格式**: HTML 表格
- **表頭結構**: MultiIndex（多層）或單層（需兼容）
- **目標對象**: 「外資及陸資」或「外資」

---

## 🎯 目標欄位定義

### 表格中需要尋找的欄位

| 欄位類別 | 欄位路徑 (MultiIndex) | 欄位關鍵字 (單層) | 說明 | 資料類型 |
|---------|---------------------|-----------------|------|---------|
| 篩選條件 | 身份別 | 身份別, 身份 | 用於篩選外資 | string |
| **目標資料** | **未平倉餘額 > 多方 > 口數** | **未平倉, 多方, 口** | **多方未平倉口數** | **integer** |

*注意：F01 是抓取「淨額」(多-空)，F02 僅需抓取「多方」口數。*

### 回傳資料格式（統一文字格式 v5.0）

**✅ 成功時**:
```
F02: 台指期貨外資 [未平倉] [多方] : 18,268 口 [TAIFEX]
```

**❌ 失敗/錯誤時**:
```
F02 錯誤: 該日無交易資料（可能是假日或休市日） [TAIFEX]
F02 錯誤: 連線逾時，請檢查網路連線 [TAIFEX]
```

**格式說明**:
- 模組代號: `F02` (大寫)
- 標題: `台指期貨外資`
- 標籤: `[未平倉] [多方]` (注意這裡是多方，不是多空淨額)
- 数值: 口數，使用千分位逗號 (如 `18,268`)
- 來源: `[TAIFEX]`
