# f03_fetcher 開發規範書

> 📌 **請先閱讀**: [共同開發規範書](../共同開發規範書_V1.md)
> 本文件只包含 f03 模組的專屬規範

**模組編號**: f03
**模組名稱**: f03_fetcher
**功能**: 抓取台指期貨外資的**未平倉空方口數** (Open Interest - Short)
**資料來源**: 台灣期貨交易所 (TAIFEX)
**難度**: ⭐⭐☆☆☆ (2/5)

**⚠️ 重要限制**: 本模組使用的 API 端點無視日期參數，永遠回傳最後交易日資料（同 F01/F02）

---

## 📊 資料來源

### API 端點
```
https://www.taifex.com.tw/cht/3/futContractsDate?queryType=1&marketCode=0&date=YYYY/MM/DD
```

### 資料特徵
- **格式**: HTML 表格
- **表頭結構**: MultiIndex（多層）或單層（需兼容）
- **目標對象**: 「外資及陸資」或「外資」

---

## 🎯 目標欄位定義

### 表格中需要尋找的欄位

| 欄位類別 | 欄位路徑 (MultiIndex) | 欄位關鍵字 (單層) | 說明 | 資料類型 |
|---------|---------------------|-----------------|------|---------|
| 篩選條件 | 身份別 | 身份別, 身份 | 用於篩選外資 | string |
| **目標資料** | **未平倉餘額 > 空方 > 口數** | **未平倉, 空方, 口** | **空方未平倉口數** | **integer** |

### 回傳資料格式（統一文字格式 v5.0）

**✅ 成功時**:
```
F03: 台指期貨外資 [未平倉] [空方] : 48,000 口 [TAIFEX]
```

**❌ 失敗/錯誤時**:
```
F03 錯誤: 該日無交易資料（可能是假日或休市日） [TAIFEX]
```

**格式說明**:
- 模組代號: `F03` (大寫)
- 標題: `台指期貨外資`
- 標籤: `[未平倉] [空方]`
- 數值: 口數，使用千分位逗號
- 來源: `[TAIFEX]`
