# F06 模組設計規格書

> 臺指選擇權波動率指數抓取模組
>
> **版本**: v1.0 OpenSpec  
> **狀態**: 開發中  
> **作者**: Claude OpenSpec  
> **最後更新**: 2025-12-15

---

## 【目標】

抓取台灣期交所 (TAIFEX) 臺指選擇權波動率指數（簡稱波動率指數或 VIX），提供統一文字格式的輸出。

**功能範圍:**

- 抓取當日臺指選擇權波動率指數
- 精度：小數後 2 位
- 數據源：台灣期交所官方網站
- 時間範圍：當天數據

---

## 【資料來源】

### URL

```
https://www.taifex.com.tw/cht/7/vixMinNew
```

### 特性

- **認證**: 無需
- **API Key**: 無需
- **返回格式**: HTML 表格
- **更新頻率**: 日更新
- **查詢方式**: 僅查詢當天數據
- **歷史數據**: 當天

### 已知限制

- 僅支援當天波動率查詢
- 非交易日無數據
- 市場休市時無更新

---

## 【輸出規格】

### 成功情況

```
YYYY.MM.DD  F06: 臺指選擇權波動率指數 : XX.XX [TAIFEX]
```

**範例:**

```
2025.12.15  F06: 臺指選擇權波動率指數 : 18.50 [TAIFEX]
```

### 失敗情況

```
F06 錯誤: [錯誤訊息] [TAIFEX]
```

**範例:**

```
F06 錯誤: 該日無交易資料（可能是假日或休市日） [TAIFEX]
```

### 異常情況

```
F06 錯誤: [訊息] [TAIFEX] (YYYY-MM-DD HH:MM:SS, [上下文])
```

**範例:**

```
F06 錯誤: 連線逾時，請檢查網路連線 [TAIFEX] (2025-12-15 14:30:45, timeout=30s)
```

## 【數據字段】

### 抓取字段

| 字段 | 說明 | 類型 | 精度 | 範例 |
|------|------|------|------|------|
| vix_value | 波動率指數數值 | float | 小數後 2 位 | 18.50 |

### 源數據格式

HTML 表格格式，需要：

1. 尋找包含波動率指數的表格
2. 提取數值
3. 驗證數值有效性（正數，合理範圍）

---

## 【異常處理】

### 處理的異常類型

| 異常類型 | 觸發條件 | 日誌級別 | 輸出信息 |
|---------|---------|---------|---------|
| ValueError | 日期格式錯誤 | INFO | 日期格式錯誤，請使用 YYYY-MM-DD |
| requests.Timeout | 連線逾時 (30s) | ERROR | 連線逾時，請檢查網路連線 |
| requests.HTTPError | HTTP 錯誤 (4xx/5xx) | ERROR | HTTP 錯誤 {status_code} |
| requests.RequestException | 其他網路錯誤 | ERROR | 網路請求失敗: {error} |
| Exception | 未預期的錯誤 | ERROR | 未預期的錯誤: {error} |

### 非交易日處理

- **條件**: HTML 解析失敗或無表格數據
- **输出**: `F06 錯誤: 該日無交易資料（可能是假日或休市日） [TAIFEX]`
- **日誌**: WARNING 級別

## 【核心邏輯】

### fetch(date: str) -> str 函數流程

```
1. 輸入驗證
   ├─ 檢查日期格式 (YYYY-MM-DD)
   └─ 若格式錯誤 → 返回 ValueError 異常信息

2. 發送請求
   ├─ 構建 URL
   ├─ 設定 User-Agent（模擬瀏覽器）
   ├─ 發送 GET 請求 (timeout=30s)
   └─ 若超時 → 返回 Timeout 異常信息

3. HTML 解析
   ├─ 使用 pandas.read_html() 解析表格
   ├─ 尋找包含波動率指數的表格
   ├─ 若找不到 → 返回「非交易日」信息
   └─ 若 HTTP 錯誤 → 返回 HTTPError 異常信息

4. 數據提取
   ├─ 從表格中尋找波動率數值
   ├─ 驗證數值有效性（正數）
   ├─ 格式化到小數後 2 位
   └─ 若失敗 → 返回「無交易資料」信息

5. 輸出格式化
   ├─ 轉換日期格式 (YYYY-MM-DD → YYYY.MM.DD)
   ├─ 組合成統一文字格式
   └─ 返回成功結果

6. 異常捕捉（全程）
   └─ 任何異常 → 轉為文字格式返回
```

## 【測試案例】

### 測試 1: 正常交易日

```
輸入: 2025-12-12 (週五)
預期: 成功，返回波動率指數數值
範例: 2025.12.12  F06: 臺指選擇權波動率指數 : 18.50 [TAIFEX]
```

### 測試 2: 非交易日 (假日)

```
輸入: 2025-12-14 (週日)
預期: 失敗，顯示無交易資料
範例: F06 錯誤: 該日無交易資料（可能是假日或休市日） [TAIFEX]
```

### 測試 3: 日期格式錯誤

```
輸入: 2025-12/12 (錯誤格式)
預期: 失敗，顯示日期格式錯誤
範例: F06 錯誤: 日期格式錯誤，請使用 YYYY-MM-DD [TAIFEX]
```

### 測試 4: 網路異常（模擬超時）

```
輸入: 2025-12-12 (但 API 無回應)
預期: 異常，顯示連線逾時
範例: F06 錯誤: 連線逾時，請檢查網路連線 [TAIFEX] (2025-12-15 14:30:45, timeout=30s)
```

## 【限制與已知問題】

1. **時間範圍**: 只能查詢當天數據
2. **非交易日**: 無法區分真正的非交易日和臨時異常
3. **數據延遲**: 可能有數分鐘的延遲
4. **API 變化**: 若 TAIFEX 網站改版，需要更新解析邏輯
