## 🔧 技術細節

### Selenium 自動化流程

```
1. 驗證日期格式 (YYYY-MM-DD)
2. 啟動 Chrome (WebDriver Manager)
3. 訪問 MIS URL: https://mis.taifex.com.tw/futures/VolatilityQuotes/
4. 等待頁面加載 (3秒)
5. 尋找「接受」按鈕 (免責聲明)
6. 點擊免責聲明 (自動)
7. 等待表格渲染 (1秒)
8. 取得頁面 HTML
9. 使用 pandas.read_html 解析表格
10. 尋找「目前指數」欄位
11. 提取 VIX 值 (浮點數)
12. 格式化輸出
13. 關閉 Chrome
```
