# F06: 台指期貨選擇權波動率指數 (TVIX) 開發規格

> **模組代號**: `f06_fetcher`
> **資料來源**: TAIFEX 波動率歷史資料 (vixHistoryDates / vixMinNew)
> **難度**: ⭐⭐☆☆☆

---

## 📖 使用說明

> 💡 **給外包開發者**：
> 1. 本模組需抓取 **臺指選擇權波動率指數 (TAIWAN VIX)** 的當日收盤數值。
> 2. 目標欄位通常稱為「收盤指數」或「臺指選擇權波動率指數」。

---

## 📋 專案目標

抓取 **TVIX (Taiwan VIX)** 的 **當日收盤指數**。

---

## 📂 交付檔案

- **檔名**: `f06_fetcher.py`
- **MODULE_ID**: `"f06"`
- **存放位置**: `dev/f06_package/` (開發) -> `modules/` (部署)

---

## 📊 資料來源規格

### 基本資訊
- **URL**: `https://www.taifex.com.tw/cht/7/vixMinNew` (官方每日報表)
- **抓取方式**: HTML 表格爬蟲
- **資料來源標記**: `source: "TAIFEX"`
- **更新頻率**: 每日盤後 (約 14:00 後)

> [!NOTE]
> 本模組 **不抓取** MIS 即時行情 (`mis.taifex.com.tw`)，僅抓取交易所正式公告之歷史數據。
> 若在當日報表產出前執行，回傳「該日無交易資料」為正常現象。

### 挑戰與注意事項
> [!IMPORTANT]
> **資料提取挑戰**:
> - VIX 資料頁面可能需要 POST 參數，或使用 `vixMinNew` 取得最近資料。
> - 若 `vixMinNew` 表格中數值為 NaN，需嘗試 POST `vixHistoryDates`。

---

## 🔍 需抓取的欄位定義

| 欄位名稱 | 說明 | 處理方式 |
|---------|------|---------|
| `臺指選擇權波動率指數` | VIX 指數值 | 提取對應日期的數值 |
| `收盤指數` | (備用名稱) | 提取數值 |

## 📝 輸出格式定義

### 成功時
```
[YYYY.MM.DD]  F06: 臺指選擇權波動率指數 : [指數] [TAIFEX]
```

**範例**：
```
2025.12.10  F06: 臺指選擇權波動率指數 : 15.45 [TAIFEX]
```

```
[YYYY.MM.DD]  F06 錯誤: [錯誤訊息] [TAIFEX]
```

## 🛠️ 實作邏輯摘要

1. **嘗試主要 URL (`vixMinNew`)**:
   - 發送 GET 請求。
   - 解析表格，尋找「日期」與「指數」欄位。
   - 若成功找到當日數據，回傳成功。
2. **(備援) 嘗試歷史 URL (`vixHistoryDates`)**:
   - 若前者失敗，發送 POST 請求 (`queryStartDate=DATE`, `queryEndDate=DATE`)。
   - 解析表格。
3. **格式化輸出**: 
   - 數值通常為浮點數 (e.g. 14.52)，保留原樣或轉為 float 檢查。
