【測試標準 - 四大檢查項目】
1. ✅ 輸出格式正確（符合 v5.0 規範）
2. ✅ 編碼正確（UTF-8，無亂碼）
3. ✅ 錯誤處理完善（不拋出未捕捉的例外）
4. ✅ 測試覆蓋率充足（正常 + 異常 + 錯誤情境）

【統一文字格式 v5.0 驗證標準】
📌 成功格式檢查清單：
   ✓ 以 `FXX:` 開頭（如 F01:）
   ✓ 包含標題與標籤（如 [未平倉] [多空淨額]）
   ✓ 包含數值與單位（如 123,456 口、+12,345 口）
   ✓ 以 `[來源: xxx]` 結尾

📌 錯誤格式檢查清單：
   ✓ 以 `[` 開頭
   ✓ 包含日期（YYYY.MM.DD 格式）
   ✓ 包含 `FXX 錯誤:` 訊息說明
   ✓ 包含 `source: xxx` 來源標記

【測試流程 - 六步驟標準作業】
Step 1: 手動測試
        └─ 執行基本功能測試，驗證核心功能正常運作
        
Step 2: 建立自動化腳本
        └─ 開發 test_fXX_auto.py，參考 test_f01_auto.py 範例
        
Step 3: 執行自動化測試
        └─ 批次執行所有測試案例，記錄執行結果
        
Step 4: 分析結果
        └─ 統計通過率與失敗項目，找出問題模式
        
Step 5: 撰寫報告
        └─ 記錄測試結果、發現問題與改善建議
        
Step 6: 更新文件
        └─ 更新規範書的測試章節、已知限制與使用範例

python modules/f0X_fetcher.py 2025-12-04

# 整合測試（透過 run.py）
python run.py 2025-12-04 --module f0X_fetcher

# 自動化測試（批次執行）
python dev/f0X_package/test_f0X_auto.py

# 檢查輸出檔案內容
Get-Content data/YYYY-MM-DD_f0X_fetcher.txt -Encoding UTF8
