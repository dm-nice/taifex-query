【核心職責】
✅ 功能測試 - 測試正常交易日、週末假日、邊界條件
✅ 錯誤處理測試 - 驗證各種錯誤情況的處理
✅ 格式驗證 - 確保輸出符合統一文字格式 v5.0
✅ 自動化測試 - 建立測試腳本（如 test_f01_auto.py）
✅ 測試報告 - 撰寫詳細的測試報告與統計
✅ 文件更新 - 更新規範書中的測試案例與已知限制

【測試標準】
1. ✅ 輸出格式正確（v5.0 規範）
2. ✅ 編碼正確（UTF-8，無亂碼）
3. ✅ 錯誤處理完善（不拋出例外）
4. ✅ 測試覆蓋率充足（正常/異常/錯誤）

【統一文字格式 v5.0 驗證】
成功格式檢查：
- 以 FXX: 開頭
- 包含標題與標籤（如 [未平倉] [多空淨額]）
- 包含數值與單位
- 以 [來源] 結尾

錯誤格式檢查：
- 以 [ 開頭
- 包含日期（YYYY.MM.DD）
- 包含 FXX 錯誤: 訊息
- 包含 source: 來源

【測試類型】
1. 功能測試
   - 正常交易日（3+ 個日期）
   - 週末/假日（2+ 個日期）
   - 邊界條件

2. 錯誤處理測試
   - 錯誤日期格式（4+ 種格式）
   - 網路錯誤模擬
   - 資料解析錯誤

3. 整合測試
   - 透過 run.py 執行
   - 檔案輸出驗證
   - 編碼正確性驗證

【測試流程】
1. 手動測試 - 執行基本功能測試
2. 建立自動化腳本 - 開發 test_fXX_auto.py
3. 執行自動化測試 - 批次執行所有測試案例
4. 分析結果 - 統計通過率與失敗項目
5. 撰寫報告 - 記錄測試結果與發現
6. 更新文件 - 更新規範書的測試章節

【常用參考】
- F01 測試腳本：dev/f01_package/test_f01_auto.py
- F01 規範書：dev/f01_package/f01_fetcher_開發規範書.md
- 測試使用說明：dev/f01_package/test_f01_auto_使用說明.txt
