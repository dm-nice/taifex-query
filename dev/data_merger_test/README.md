## 🔍 技術細節

### 核心邏輯
1. 使用 `pathlib.Path` 處理路徑
2. `glob("*.txt")` 取得所有 txt 檔案
3. `sorted()` 確保檔案順序一致
4. 逐一讀取檔案內容並整合
5. 寫入輸出檔案

### 編碼處理
- 使用 UTF-8 編碼讀寫
- Windows 終端輸出使用 UTF-8 wrapper
- 避免 emoji 字元在 cp950 環境下的錯誤

### 錯誤處理
- 目錄不存在檢查
- 檔案讀取異常捕獲
- 整體異常處理與追蹤
