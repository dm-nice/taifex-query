# 資料整合工具使用說明

## 📖 簡介

這是一個簡單的資料整合工具，用於將 `data` 目錄下的所有 `.txt` 檔案內容整合到單一檔案 `Total_data.txt` 中。

按照 **OpenSpec 開發試驗版** 流程開發，快速、簡單、實用。

---

## 🚀 使用方法

### 方法 1: 雙擊執行批次檔 (最簡單)

1. 進入 `C:\Taifex\dev\data_merger_test\` 目錄
2. 雙擊 `merge_data.bat`
3. 查看輸出訊息
4. 完成後檢查 `Total_data.txt`

### 方法 2: 命令列執行

```bash
# 進入工具目錄
cd C:\Taifex\dev\data_merger_test

# 執行整合程式
python merge_data.py
```

## 📊 輸出格式

整合後的檔案格式如下：

```
# 台灣期貨 20 因子預測系統 - 整合資料
# 整合時間: 2025-12-18 10:22:27
# 資料來源: C:\Taifex\data
# 檔案數量: 7
#======================================================================

## 2025-12-18_0959_f01_fetcher.txt
2025.12.18  F01: 台指期貨外資 [未平倉] [多空淨額] : -29,032 口  [...]

## 2025-12-18_0959_f02_fetcher.txt
2025.12.18  F02: 台指期貨外資 [未平倉] [多方] : 16,177 口  [...]

... (以此類推)
```

### 檔案結構
- **標題區**: 整合時間、來源目錄、檔案數量
- **資料區**: 每個原始檔案的檔名和內容
- **分隔**: 使用空行分隔各檔案內容

---

## ✨ 功能特點

1. **自動搜尋**: 自動找到 `data` 目錄下所有 `.txt` 檔案
2. **排序整合**: 按檔名排序，確保順序一致
3. **完整資訊**: 包含檔名、時間戳、來源路徑
4. **UTF-8 編碼**: 正確處理中文字元
5. **錯誤處理**: 單一檔案讀取失敗不影響整體
6. **即時預覽**: 顯示前 10 行預覽

## 📋 常見問題

### Q1: 如果 data 目錄下沒有檔案怎麼辦？
**A**: 程式會顯示錯誤訊息：`錯誤: data 目錄下沒有 .txt 檔案`

### Q2: 可以修改輸出路徑嗎？
**A**: 可以，編輯 `merge_data.py` 中的 `output_file` 變數即可

### Q3: 支援子目錄嗎？
**A**: 目前不支援，只處理 `data` 目錄下的檔案，不包含子目錄

### Q4: 如何只整合特定日期的檔案？
**A**: 可以修改程式，使用更精確的 glob 模式，例如：
```python
txt_files = sorted(data_dir.glob("2025-12-18*.txt"))
```
