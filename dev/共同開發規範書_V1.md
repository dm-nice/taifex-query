### 🎯 統一文字格式規範

#### ✅ 成功時格式（v4.0 與 v5.0）
```
[ YYYY.MM.DD  FXX{描述}   source: {來源} ]  # v4.0（舊格式）
FXX: {描述} [source]             # v5.0（新格式，可省略括號與前置日期）
```

**範例**:
```
[ 2025.12.03  F01台指期外資淨額 -29,439 口（多方 19,214，空方 48,653）   source: TAIFEX ]  # v4.0
F11: 台灣股票大盤當日收盤價 : 28,400.73 [mis.twse.com.tw]  # v5.0
```

**格式元素**:
- `[ ... ]` - 中括號 + 空格
- `YYYY.MM.DD` - 日期格式（點分隔）
- `FXX` - 模組代號（大寫字母 + 數字）
- `{描述}` - 模組特定的中文描述 + 數據
- `{數值}` - 使用千分位逗號（如 -29,439）
- `source: {來源}` - 固定格式標記資料來源

#### ❌ 錯誤時格式
```
[ YYYY.MM.DD  FXX 錯誤: {錯誤訊息}   source: {來源} ]
```

**範例**:
```
[ 2025.11.30  F01 錯誤: 該日無交易資料（可能是假日或休市日）   source: TAIFEX ]
```

**規則**:
- 錯誤標記: `{模組代號} 錯誤: {錯誤訊息}`
- 不區分 failed/error（統一為錯誤格式）
- 錯誤訊息使用中文，清楚描述問題

### 🔧 必須實作的函式

```python
def fetch(date: str) -> str:
    """
    抓取指定日期的資料

    Args:
        date: 查詢日期，格式 YYYY-MM-DD

    Returns:
        統一格式的文字字串
    """
```

### 📝 格式化函式範本

```python
from typing import Dict, Optional

def format_fxx_output(date: str, status: str, data: Optional[Dict] = None, error: Optional[str] = None) -> str:
    """格式化輸出為統一文字格式"""
    date_formatted = date.replace("-", ".")  # YYYY-MM-DD → YYYY.MM.DD

    if status == "success" and data:
        # 根據模組特性格式化成功輸出
        value = data.get("some_value", 0)
        return f"[ {date_formatted}  FXX{描述} {value:,}   source: {來源} ]"
    else:
        error_msg = error or "未知錯誤"
        return f"[ {date_formatted}  FXX 錯誤: {error_msg}   source: {來源} ]"
```

### ✅ 四大規範

1. ✅ **回傳類型**：必須是 `str`（統一文字格式）
2. ✅ **錯誤處理**：所有錯誤都轉換為文字格式，不拋出例外
3. ✅ **日期格式**：輸入 `YYYY-MM-DD` → 輸出 `YYYY.MM.DD`
4. ✅ **模組代號**：大寫（F01, F02...）

## F13: 台灣加權股價指數與 20 日均線距離

- **資料來源**：TWSE MI_INDEX JSON（`https://www.twse.com.tw/rwd/zh/afterTrading/MI_INDEX?response=json&type=IND&date=YYYYMMDD`）會回傳包含 `stat`、`fields` 與 `data` 的表格，`fields` 中會帶 `TAIEX` 或 `發行量加權股價指數` 關鍵字。
- **主要流程**：對查詢日往前 60 個交易日呼叫 `MI_INDEX`，挑選符合 `TAIEX`/`加權股價指數` 的收盤價，累積 20 筆有效數字，計算 `ma20` 後用 `distance = ma20 - closing` 回傳；若查不到資料則回 `failed`（假日或尚未公布）。
- **錯誤處理**：網路/HTTP 錯誤回 `error: 無法連線 TWSE MI_INDEX`，若欄位漂移或 `stat != OK` 也會記 log 並回 `failed`，可參考 `debug/debug_f13_mi.py` 的欄位檢查紀錄。
- **輸出格式**：`2025.12.11  F13: 台灣加權股價指數與 20 日均線距離 : -552.87 點 [twse.com.tw]`，`data` 可附 `distance`、`ma20`、`closing`、`actual_date` 供比對。

## F14: 台積電當日收盤價

- **資料來源**：`https://www.twse.com.tw/exchangeReport/STOCK_DAY?response=html&stockNo=2330&date=YYYYMMDD`，會回傳多層表頭的 HTML 表格，需要展開欄位名稱才能看到 `收盤價`。
- **主要流程**：用 `pandas.read_html` 解析表格、逐列將民國日期轉成 `YYYY-MM-DD`、找出查詢日的 row、將 `收盤價` 轉為浮點數並格式化為 `1,470.00`；若對應 row 不存在則回 `failed`。
- **錯誤處理**：連線失敗回 `error: 無法連線 TWSE STOCK_DAY`；若欄位消失或資料格式異常也會 `error` 並寫 log；資料缺失（假日、資料延遲）則回 `failed: 該日資料不存在（假日或資料延遲）`。
- **輸出格式**：`2025.12.11  F14: 台積電當日收盤價 : 1,470.00 [twse.com.tw]`，`data` 可附 `closing` 與 `actual_date`。

## F15: 台積電當日漲跌價差

- **資料來源**：同樣使用 `https://www.twse.com.tw/exchangeReport/STOCK_DAY?response=html&stockNo=2330&date=YYYYMMDD` 的表格，這次目標欄位為 `漲跌價差`。
- **主要流程**：展開欄位與日期、先試著用欄位提供的 `漲跌價差`（可包含 `X0.00`），若無法解析再取前一個交易日 `收盤價` 差值；最後用 `f"{value:+,.2f}"` 回傳。 
- **錯誤處理**：網路錯誤 `error: 無法連線 TWSE STOCK_DAY`；欄位缺失或數值異常回 `error` 並寫 log；假日/延遲回 `failed: 該日資料不存在（假日或資料延遲）`。
- **輸出格式**：`2025.12.11  F15: 台積電當日漲跌價差 : +0.00 點 [twse.com.tw]`（`X0.00` 仍會回 `+0.00`），`data` 包含 `change`、`actual_date`、`source`。

## F16: 台積電當日成交股數

- **資料來源**：同樣使用 `https://www.twse.com.tw/exchangeReport/STOCK_DAY?response=html&stockNo=2330&date=YYYYMMDD` 的 HTML 表格。
- **主要流程**：解析表格、展開欄位、將民國日期轉成 `YYYY-MM-DD` 後挑出查詢日的 row，從 `成交股數` 取出數字（移除千分號與非數字字元），再以 `f"{value:,}"` 產生帶千分號的整數並附上 `張`。
- **錯誤處理**：網路/HTTP 錯誤或欄位缺失回 `error: 無法連線 TWSE STOCK_DAY`；若遇到假日/延遲或無資料則回 `failed: 該日資料不存在（假日或資料延遲）`。
- **輸出格式**：`2025.12.11  F16: 台積電當日成交股數 : 31,018,417 張 [twse.com.tw]`，`data` 可帶入 `turnover`、`actual_date` 與 `source`。
- **驗收留存**：對應輸出/日誌位於 `data/2025-12-11_1609_f16_fetcher_dev_dev.txt` 與 `data/2025-12-11_1609_run_dev.log`。

## F17: 台灣股票外資及陸資買賣差額

- **資料來源**：`https://www.twse.com.tw/fund/BFI82U?response=json&date=YYYYMMDD` 會回傳 `stat`、`fields` 與 `data`，`data` 裡的 `單位名稱` 欄位會出現「外資」與「陸資」的組合。
- **主要流程**：呼叫 BFI82U JSON，從 `fields` 中找出帶 `買賣差額` 的欄位索引，再在 `data` 中挑選第一個同時包含「外資」與「陸資」的列，將該列的差額（帶有千分號與括號）解析為整數、除以 1 億換算為億元，最後以 `+/-` 搭配兩位小數格式回傳；若欄位漂移、資料空白或 `stat != OK` 則回 `failed`，網路錯誤回 `error`。
- **錯誤處理**：網路/HTTP 錯誤回 `error: 無法連線 TWSE BFI82U`；若 JSON 無法解析或 `stat` 不是 `OK` 則回 `error: TWSE 回傳格式解析失敗`；找不到外資差額、差額非數值、`data` 為空、或 `fields` 未含差額欄位都會回 `failed` 並附上欄位/行號供調查。
- **輸出格式**：`2025.12.11  F17: 台灣股票外資及陸資買賣差額 : -189.77 億元 [twse.com.tw]`，`data` 可帶 `difference` 與 `source`。
- **驗收留存**：對應輸出/日誌存放於 `data/2025-12-11_1658_f17_fetcher_dev_dev.txt` 與 `data/2025-12-11_1658_run_dev.log`。

```
開發階段              驗收階段              正式階段
```

### 📁 run.py 執行與 data/ 輸出

- 使用 `run.py [日期] [模式] [--module 模組名稱]` 透過統一入口執行模組。
- `data/` 由 `run.py` 自動建立，輸出檔名格式為 `YYYY-MM-DD_HHMM_模組名稱[_dev].txt` 承載 v4/v5 文字輸出。
- 同一支模組在正式/驗收模式會產生不同檔名（末尾 `_dev`），日誌 (.log) 與輸出檔一併保留紀錄。
- 若需要調整輸出格式，只要讓 `fetch()` 回傳符合格式的字串，log 與 `data/` 會自動同步。

## 資料格式標準

### 統一文字格式定義

所有模組必須回傳統一格式的文字字串，格式如下：

#### ✅ 成功時

```
[ 2025.12.03  F01台指期外資淨額 -29,439 口（多方 19,214，空方 48,653）   source: TAIFEX ]
```

**格式規範**：
- 外框: `[ ... ]` (中括號 + 空格)
- 日期: `YYYY.MM.DD` (點分隔)
- 模組代號: 大寫字母 + 數字 (如 F01, F02)
- 描述: 模組特定的中文描述 + 數據
- 來源: 固定格式 `source: {來源名稱}`

#### ❌ 失敗/錯誤時

```
[ 2025.11.30  F01 錯誤: 該日無交易資料（可能是假日或休市日）   source: TAIFEX ]
```

**格式規範**：
- 錯誤標記: `{模組代號} 錯誤: {錯誤訊息}`
- 不再區分 failed/error (統一為錯誤格式)
- 錯誤訊息使用中文，清楚描述問題

### 日期格式轉換

```python
date = "2025-12-03"  # 輸入
date_formatted = date.replace("-", ".")  # 轉換
# 輸出: "2025.12.03"
```

### 模組代號提取

從模組名稱提取代號：

```python
import re

def extract_module_id(module_name: str) -> str:
    """提取模組代號"""
    match = re.match(r'([a-z]\d+)', module_name, re.IGNORECASE)
    if match:
        return match.group(1).upper()
    return "FXX"
```

## 錯誤處理規範

### 狀態碼使用時機

| 狀態碼 | 使用時機 | 範例 |
|--------|---------|------|
| success | 成功取得資料 | 正常交易日，資料完整 |
| failed | 業務邏輯失敗 | 假日無資料、找不到欄位、欄位格式異常 |
| error | 技術性錯誤 | 網路逾時、HTTP 錯誤、日期格式錯誤 |

### 必須處理的錯誤情況

#### 1. 網路相關錯誤 → error

```python
try:
    response = requests.get(url, timeout=30)
    response.raise_for_status()
except requests.Timeout:
    return {
        "module": MODULE_ID,
        "date": date,
        "status": "error",
        "error": "連線逾時，請檢查網路連線"
    }
except requests.HTTPError as e:
    return {
        "module": MODULE_ID,
        "date": date,
        "status": "error",
        "error": f"HTTP 錯誤 {e.response.status_code}"
    }
except requests.RequestException as e:
    return {
        "module": MODULE_ID,
        "date": date,
        "status": "error",
        "error": f"網路請求失敗: {str(e)}"
    }
```

#### 2. 資料格式錯誤 → failed

```python
# 找不到表格
if len(tables) == 0:
    return {
        "module": MODULE_ID,
        "date": date,
        "status": "failed",
        "error": "該日無交易資料（可能是假日或休市日）"
    }

# 找不到目標欄位
if target_col is None:
    return {
        "module": MODULE_ID,
        "date": date,
        "status": "failed",
        "error": f"找不到目標欄位，可用欄位: {df.columns.tolist()}"
    }
```

#### 3. 參數錯誤 → error

```python
try:
    datetime.strptime(date, "%Y-%m-%d")
except ValueError:
    return {
        "module": MODULE_ID,
        "date": date,
        "status": "error",
        "error": "日期格式錯誤，請使用 YYYY-MM-DD"
    }
```

#### 4. 未預期的錯誤 → error

```python
except Exception as e:
    logger.exception("未預期的錯誤")
    return {
        "module": MODULE_ID,
        "date": date,
        "status": "error",
        "error": f"未預期的錯誤: {str(e)}"
    }
```

### 錯誤訊息撰寫原則

✅ **好的錯誤訊息**：
- "找不到身份別欄位，可用欄位: ['商品', '交易人', '多方']"
- "該日無交易資料（可能是假日或休市日）"
- "連線逾時，請檢查網路連線"

❌ **不好的錯誤訊息**：
- "錯誤" （太籠統）
- "Error: KeyError" （英文 + 技術術語）
- "list index out of range" （Python 原始錯誤）

## 常見問題 FAQ

### Q1: 為什麼要用英文 key 但中文訊息？

**A**: 這是混合模式設計：
- **英文 key**: 符合程式設計慣例，避免編碼問題，便於國際化
- **中文訊息**: 使用者友善，訊息清楚易懂

範例：
```json
{
  "status": "success",              // ← 程式用英文 key
  "summary": "台指期外資淨額 -29,032 口"  // ← 使用者看中文訊息
}
```

### Q2: data 裡面的 key 要用英文還是中文？

**A**: **必須用英文**！

```json
{
  "data": {
    "long_position": 18268,    // ✅ 正確
    "short_position": 47300    // ✅ 正確
  }
}

// ❌ 錯誤
{
  "data": {
    "多方口數": 18268,
    "空方口數": 47300
  }
}
```

但在 `summary` 可以用中文：
```json
{
  "summary": "多方口數 18,268，空方口數 47,300"  // ✅ 這裡可以用中文
}
```

### Q3: status 應該用 "success" 還是 "成功"？

**A**: **必須用 "success"**！

```python
# ✅ 正確
"status": "success"
"status": "failed"
"status": "error"

# ❌ 錯誤
"status": "成功"
"status": "失敗"
"status": "錯誤"
```

### Q4: 假日無資料應該回傳 failed 還是 error？

**A**: **回傳 failed**

- `failed`: 業務邏輯失敗（假日本來就沒資料，這是正常的）
- `error`: 技術性錯誤（例如網路斷線，這是異常的）

```python
# ✅ 正確
if len(tables) == 0:
    return {
        "status": "failed",
        "error": "該日無交易資料（可能是假日或休市日）"
    }
```

### Q5: 錯誤訊息要寫多詳細？

**A**: 盡量詳細，但要用中文！

```python
# ✅ 很好：詳細且有幫助
"error": "找不到身份別欄位，可用欄位: ['商品', '交易人', '多方', '空方']"

# ⚠️ 普通：有基本資訊
"error": "找不到身份別欄位"

# ❌ 不好：太籠統
"error": "資料錯誤"

# ❌ 很糟：英文 + 技術術語
"error": "KeyError: '身份別'"
```

### Q6: 需要處理編碼問題嗎？

**A**: 通常不需要，但建議設定：

```python
response = requests.get(url, timeout=30)
response.encoding = "utf-8"  # ← 明確指定 UTF-8
```

```python
## 🧪 Debug 腳本管理

"""
最小可用的 fetcher 範例
"""

import sys
import json
import requests
import pandas as pd
from datetime import datetime

MODULE_ID = "example"

def fetch(date: str) -> dict:
    """抓取資料"""
    try:
        # 驗證日期
        datetime.strptime(date, "%Y-%m-%d")
        
        # 發送請求
        url = "https://example.com/api"
        response = requests.get(url, timeout=30)
        response.raise_for_status()
        
        # 解析資料
        data = response.json()
        
        # 回傳成功
        return {
            "module": MODULE_ID,
            "date": date,
            "status": "success",
            "summary": "成功取得資料",
            "data": {
                "value": data["value"]
            },
            "source": "EXAMPLE"
        }
        
    except requests.Timeout:
        return {
            "module": MODULE_ID,
            "date": date,
            "status": "error",
            "error": "連線逾時"
        }
    except Exception as e:
        return {
            "module": MODULE_ID,
            "date": date,
            "status": "error",
            "error": f"未預期的錯誤: {str(e)}"
        }

def main():
    """測試用"""
    test_date = sys.argv[1] if len(sys.argv) > 1 else '2025-12-01'
    result = fetch(test_date)
    print(json.dumps(result, ensure_ascii=False, indent=2))
    sys.exit(0 if result.get("status") == "success" else 1)

if __name__ == '__main__':
    main()
```
