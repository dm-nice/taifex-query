# F05: 台指期貨選擇權總成交量 開發規格

> **模組代號**: `f05_fetcher`
> **資料來源**: TAIFEX 選擇權每日交易行情 (optDailyMarketReport)
> **難度**: ⭐⭐☆☆☆

---

## 📖 使用說明

> 💡 **給外包開發者**：
> 1. 本模組需計算 **TXO (台指選)** 的 **總成交量**。
> 2. 資料來源為 HTML 表格，需將所有契約（不同到期日、履約價、買賣權）的「成交量」欄位數值進行 **加總**。

---

## 📋 專案目標

抓取 **台指選擇權 (TXO)** 的 **當日總成交量**。

---

## 📂 交付檔案

- **檔名**: `f05_fetcher.py`
- **MODULE_ID**: `"f05"`
- **存放位置**: `dev/f05_package/` (開發) -> `modules/` (部署)

---

## 📊 資料來源規格

### 基本資訊
- **URL**: `https://www.taifex.com.tw/cht/3/optDailyMarketReport?queryDate={DATE}&marketCode=0&commodity_id=TXO`
- **抓取方式**: HTML 表格爬蟲 (`pd.read_html`)
- **表格特徵**: 單層表頭
- **商品代碼**: `TXO`
- **資料來源標記**: `source: "TAIFEX"`

### 挑戰與注意事項
> [!IMPORTANT]
> **欄位名稱陷阱**:
> - 成交量欄位名稱在 HTML 中可能顯示為 `*成交量` (帶星號) 或含有空白/換行。
> - 範例: `*成交量`, `* 成 交 量` 等。
> - **必須進行模糊比對**，且數值含有千分位逗號，需先轉型再加總。

---

## 🔍 需抓取的欄位定義

| 欄位名稱 | 說明 | 處理方式 |
|---------|------|---------|
| `*成交量` | 各合約的當日成交量 | **Sum (加總)** 所有列的數值 |

---

## 📝 輸出格式定義

### 成功時
```
[YYYY.MM.DD]  F05: 台指期貨選擇權總成交量 : [總口數] 口 [TAIFEX]
```

**範例**：
```
2025.12.10  F05: 台指期貨選擇權總成交量 : 430,688 口 [TAIFEX]
```

### 失敗時
```
[YYYY.MM.DD]  F05 錯誤: [錯誤訊息] [TAIFEX]
```

## 🛠️ 實作邏輯摘要

1. **請求資料**: 使用上述 URL，帶入查詢日期。
2. **解析表格**: 讀取第一個表格。
3. **尋找欄位**: 尋找包含「成交量」關鍵字的欄位 (應處理 `*` 和空白)。
4. **資料清洗**: 
   - 將該欄位轉為字串。
   - 移除逗號 (`,`)。
   - 處理非數字字元 (如 `-` 轉為 0)。
   - 轉為浮點數或整數。
5. **計算總和**: `total_volume = sum(volume_column)`。
6. **格式化輸出**: 產生符合 v5.0 規範的字串。
