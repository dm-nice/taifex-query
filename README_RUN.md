# run.py / run.bat 使用說明

## 簡介

`run.py` 是 Taifex 專案的模組統一執行程式，用於自動執行所有資料抓取模組並將結果儲存到 `data/` 目錄。

## 使用方式

### 方式 1：使用批次檔（推薦）

批次檔會自動過濾掉詳細的日誌訊息，只在螢幕顯示執行摘要：

```bat
REM 執行今天的資料
run.bat

REM 執行指定日期
run.bat 2025-12-15

REM 驗收模式（執行 dev/ 目錄下的模組）
run.bat 2025-12-15 dev

REM 只執行特定模組
run.bat 2025-12-15 --module f01_fetcher
```

### 方式 2：直接執行 Python（會顯示詳細日誌）

```bat
REM 執行今天的資料
python run.py

REM 執行指定日期
python run.py 2025-12-15

REM 驗收模式
python run.py 2025-12-15 dev

REM 只執行特定模組
python run.py 2025-12-15 --module f01_fetcher
```

### 方式 3：手動過濾日誌

如果想在執行 `python run.py` 時也過濾詳細日誌，可以使用：

```bat
REM Windows PowerShell
python run.py 2025-12-15 2>$null

REM Windows CMD
python run.py 2025-12-15 2>nul

REM Git Bash / Linux
python run.py 2025-12-15 2>/dev/null
```

## 輸出說明

### 螢幕輸出（使用 run.bat）

簡潔的執行摘要：

```
======================================================================
  📅 查詢日期: 2025-12-15
  ⏰ 執行時間: 2025-12-15 20:15:30
  🔧 執行模式: 正式模式
======================================================================

======================================================================
  📊 執行統計
======================================================================
  總數: 3
  ✅ 成功: 3 (100.0%)
  ⚠️  失敗: 0 (0.0%)
  ❌ 錯誤: 0 (0.0%)
  ⛔ 無效: 0 (0.0%)
======================================================================
📝 詳細日誌: C:\Taifex\data\2025-12-15_2015_run.log
======================================================================
```

### 檔案輸出

執行後會在 `data/` 目錄產生以下檔案：

1. **資料檔案**：`YYYY-MM-DD_HHMM_模組名稱.txt`
   - 例如：`2025-12-15_2015_f01_fetcher.txt`
   - 內容：模組抓取的資料結果

2. **日誌檔案**：`YYYY-MM-DD_HHMM_run.log`
   - 例如：`2025-12-15_2015_run.log`
   - 內容：完整的執行日誌，包含所有細節

## 執行模式

### 正式模式（預設）
- 執行 `modules/` 目錄下的所有模組
- 產生的檔案名稱：`YYYY-MM-DD_HHMM_模組名稱.txt`

### 驗收模式（dev）
- 執行 `dev/` 目錄下的所有模組
- 產生的檔案名稱：`YYYY-MM-DD_HHMM_模組名稱_dev.txt`
- 使用方式：`run.bat 2025-12-15 dev`

## 查看詳細日誌

所有執行細節都記錄在 log 檔案中，可以使用以下方式查看：

```bat
REM 查看最新的 log 檔案
type data\2025-12-15_2015_run.log

REM 查看最後 20 行
powershell Get-Content data\2025-12-15_2015_run.log -Tail 20
```

## 注意事項

1. **時間戳**：檔案名稱包含執行時間（HHMM），避免同一天多次執行時檔案被覆蓋
2. **日期格式**：必須使用 `YYYY-MM-DD` 格式，例如 `2025-12-15`
3. **模組目錄**：確保 `modules/` 或 `dev/` 目錄存在且包含有效的 Python 模組
4. **編碼支援**：程式自動處理 UTF-8 編碼，支援中文和表情符號

## 常見問題

### Q: 為什麼使用 run.bat 和 python run.py 輸出不同？

A: `run.bat` 會過濾掉詳細的日誌訊息（stderr），只顯示執行摘要。`python run.py` 會顯示所有日誌訊息。

### Q: 如何查看執行細節？

A: 查看 `data/` 目錄下的 `.log` 檔案，裡面包含完整的執行日誌。

### Q: 如何只執行特定模組？

A: 使用 `--module` 參數，例如：`run.bat 2025-12-15 --module f01_fetcher`

### Q: 執行時出現錯誤怎麼辦？

A: 查看 log 檔案中的錯誤訊息，或直接執行 `python run.py` 查看詳細輸出。
