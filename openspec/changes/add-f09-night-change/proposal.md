# Change: Add F09 台指期貨夜盤漲跌點數模組

## Why

F08 已提供夜盤收盤價，但缺少**夜盤漲跌點數**（相對於日盤收盤價的變化）。夜盤漲跌點數是重要的預測因子，因為：

1. **隔日開盤參考** - 夜盤漲跌直接反映市場情緒變化，影響隔日開盤方向
2. **國際市場影響** - 夜盤漲跌可量化美股、歐股對台股的影響程度
3. **價差分析** - F04 (日盤) → F08 (夜盤) 的價差，提供籌碼分析依據
4. **完整因子** - 配合 F04 (日盤收盤) + F08 (夜盤收盤) + F09 (夜盤漲跌)，形成完整的日夜盤分析體系

## What Changes

- 新增 F09 模組：`modules/f09_fetcher.py`
- 資料來源：TAIFEX 期貨每日交易行情（盤後交易時段）
- 資料欄位：「漲跌點數」或「漲跌」欄位
- 輸出格式：`2025.12.18  F09: 台指期貨夜盤漲跌點數 : +108 點 [來源URL]`

### 新增功能

- ✅ 抓取台指期貨 (TX) 近月合約夜盤漲跌點數
- ✅ 正負號顯示（+108 / -52）
- ✅ 支援歷史日期查詢
- ✅ 異常處理：連線逾時、無資料、解析失敗
- ✅ 統一輸出格式 (v5.0)

### 技術方法

- **HTTP + HTML 解析** (與 F08 相同技術)
- 使用 `requests` + `pandas.read_html`
- 查詢參數：`queryDate` + `marketCode=0` + `commodity_id=TX` + `queryType=2`
- **關鍵欄位**：「漲跌點數」或「漲跌」
